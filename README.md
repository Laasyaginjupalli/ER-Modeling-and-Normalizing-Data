# ER Modelling and Normalising Data – KBS Pty Ltd

## Project Overview

This project focuses on designing a relational database for KBS Pty Ltd, a growing online business facing challenges in managing customer, product, order, and payment information stored across separate files. It uses Entity-Relationship (ER) modelling and database normalisation principles to develop a centralised database structure, improve data organisation, reduce redundancy, and support efficient business operations.

## Objectives

- Identify key business entities, attributes, and relationships.
- Design a relational database using Entity-Relationship (ER) modelling.
- Establish primary keys and foreign keys to maintain data integrity.
- Identify relationships and cardinality between database entities.
- Apply database normalisation up to Third Normal Form (3NF).
- Reduce data duplication and improve data consistency.
- Develop a scalable database structure to support business operations and reporting.

## Key Outcomes

Designed a centralised relational database consisting of five entities: Customer, Product, Order, OrderItem, and Payment. Applied 3NF normalisation to minimise data redundancy, eliminate partial and transitive dependencies, and improve data consistency. The proposed database structure supports efficient order management, inventory tracking, payment recording, and business reporting.
